# DebtSight — Shared Interface Contracts

This document is the single source of truth for interfaces, data schemas, encodings, and contracts between all modules in DebtSight:
- **Revanth's Modules**: Loan Mathematics, Machine Learning Risk Predictor, and Integration Engine.
- **Rachan's Modules**: Android Frontend UI, Input Forms, Timeline Slider, and Results Screens.
- **Rakesh's Modules**: Unity AR Scene, ARCore Plane Tracker, and 3D Visualizer.

---

## 1. Interface Summary Matrix

| Sender | Receiver | Payload / Method Call | Description |
| :--- | :--- | :--- | :--- |
| **Frontend (Rachan)** | **Integration (Revanth)** | `LoanInputData` | User loan parameters & borrower financial context |
| **Integration (Revanth)** | **Loan Math (Revanth)** | `CalculateScheduleRequest` | Standardized loan calculation parameters |
| **Loan Math (Revanth)** | **Integration (Revanth)** | `LoanScheduleResult` | Amortization schedule, balances, totals |
| **Integration (Revanth)** | **ML Predictor (Revanth)** | `RiskFeatureVector` | `[amount, rate, tenure, lender_type, income_bracket]` |
| **ML Predictor (Revanth)** | **Integration (Revanth)** | `risk_probability` (float `0.0`–`1.0`) | Calibrated probability of default |
| **Integration (Revanth)** | **Frontend (Rachan)** | `DebtSightResult` | Full monthly balances, risk score, monthly burden indices |
| **Frontend / Bridge** | **Unity AR (Rakesh)** | `SetBurden(float)`, `SetRisk(float)` | Normalized burden and risk values in range `[0.0, 1.0]` |

## 2. Data Structures & Schemas

### 2.1 Loan Input Data (`LoanInputData`)

Passed from Frontend UI to the Integration layer.

```json
{
  "principal": 50000.0,
  "interest_rate": 36.0,
  "rate_period": "annual",
  "tenure_months": 12,
  "interest_method": "flat_rate",
  "repayment_frequency": "monthly",
  "lender_type": 2,
  "income_bracket": 1,
  "monthly_prepayment": 0.0
}
```

#### Field Specifications:
- `principal` (float, > 0): Principal loan amount in INR (₹).
- `interest_rate` (float, >= 0): Interest rate expressed as a percentage (e.g., `36.0` for 36%).
- `rate_period` (string, enum: `"annual"`, `"monthly"`): Crucial for rural India where moneylenders quote monthly rates (e.g., "3% per month" = 36% p.a.).
- `tenure_months` (int, > 0): Duration of the loan in months.
- `interest_method` (string, enum: `"flat_rate"`, `"reducing_balance"`, `"simple_interest"`): The formula used to calculate interest and schedule.
- `repayment_frequency` (string, default: `"monthly"`): Frequency of installments (`"monthly"`, `"bullet"`).
- `lender_type` (int, enum: `0, 1, 2`): Categorical code for the lending entity (see Section 3).
- `income_bracket` (int, enum: `0, 1, 2, 3`): Borrower income tier (see Section 4).
- `monthly_prepayment` (float, default: `0.0`): Optional extra monthly payment toward principal.

### 2.2 Loan Mathematics Output (`LoanScheduleResult`)

Generated by `LoanEngine.calculate()`.

```json
{
  "monthly_balance": [50000.0, 46500.0, 42800.0, "..."],
  "monthly_payment": 5666.67,
  "total_interest": 18000.0,
  "total_repayment": 68000.0,
  "debt_free_month": 12,
  "amortization_table": [
    {
      "month": 1,
      "opening_balance": 50000.0,
      "payment": 5666.67,
      "principal_paid": 4166.67,
      "interest_paid": 1500.0,
      "closing_balance": 45833.33
    }
  ]
}
```

- `monthly_balance` (`list[float]`): Sequence of outstanding balances at the end of each month (starting at month 0 or closing balance of month 1..N).

---

### 2.3 ML Risk Feature Vector & Output

#### Input Features to ML Model:
An array of 5 numeric values:
```python
[amount, rate, tenure, lender_type, income_bracket]
```
- `amount` (float): Principal in INR.
- `rate` (float): Standardized Annual Percentage Rate (APR) in percentage (e.g., 24.0).
- `tenure` (int): Duration in months.
- `lender_type` (int): Encoded integer (`0` = Bank, `1` = SHG, `2` = Informal).
- `income_bracket` (int): Encoded integer (`0`, `1`, `2`, `3`).

#### Output:
- `risk_probability` (float): Calibrated scalar between `0.0` (lowest risk) and `1.0` (highest risk).
  > **Note**: Represents relative probability of default based on trained statistical models. It is **not** a guaranteed debt-trap prediction and does not predict the exact month of default.

### 2.5 Unity AR C# Interface (`IDebtVisualizer`)

Owned by Rakesh. Unity GameObject controller script attached to the 3D visualization object (rice sack / coin stack).

```csharp
public interface IDebtVisualizer
{
```

## 3. Categorical Encodings

### 3.1 Lender Type Encoding (`lender_type`)

| Code | Category | Examples / Scope in Rural India |
| :---: | :--- | :--- |
| `0` | **Bank / Formal** | Commercial banks (SBI, Canara), Regional Rural Banks (RRBs), Microfinance Institutions (NBFC-MFIs). |
| `1` | **Self-Help Group (SHG)** | NRLM / NABARD SHGs, Joint Liability Groups (JLGs), village cooperative societies. |
| `2` | **Informal Moneylender** | Local *sahukars*, agricultural traders, commission agents, pawn brokers. |

#### Note on MUDRA:
MUDRA (*Pradhan Mantri MUDRA Yojana*) is **not** an independent lender category. It is a government refinancing product/scheme disbursed *through* Commercial Banks, RRBs, and NBFC-MFIs. In DebtSight, a MUDRA loan is encoded as `0` (**Bank / Formal**).

---

### 3.2 Income Bracket Encoding (`income_bracket`)

| Code | Monthly Income Tier (INR) | Typical Profile |
| :---: | :--- | :--- |
| `0` | < ₹10,000 / month | Daily wage agricultural laborer, marginal artisan |
| `1` | ₹10,000 – ₹25,000 / month | Small farmer, informal shopkeeper, transport driver |
| `2` | ₹25,000 – ₹50,000 / month | Semi-skilled worker, medium farmer, small enterprise owner |
| `3` | > ₹50,000 / month | Salaried employee, large business owner, commercial farmer |

## 4. Documented Interface Mismatches & Action Items

> [!WARNING] Interface Mismatch Identified: `income_bracket` Missing in Frontend Form
> **Issue**: The original Android frontend input form collected `amount`, `rate`, `tenure`, and `lender_type`, but **omitted** `income_bracket`. However, default risk cannot be assessed without income context (a ₹50,000 loan is catastrophic for an income of ₹5,000/mo, but minor for ₹50,000/mo).
> **Recommendation**: Team agreement to update Rachan's UI with a simple 4-tier income selector (e.g., single-choice visual icons or income chips) corresponding to codes `0, 1, 2, 3`.

## 5. Burden Index Definition

The combined financial burden index is computed across the loan timeline:

$$\text{burden\_index}(t) = 0.6 \times \text{normalized\_debt}(t) + 0.4 \times \text{risk}$$

Where:
- $\text{normalized\_debt}(t) = \frac{\text{monthly\_balance}[t]}{\text{principal}}$ (clamped to $[0.0, 1.0]$).
- $\text{risk} \in [0.0, 1.0]$ is the ML default probability.

> [!NOTE] Design Choice Notice
> The $0.6 / 0.4$ weight split is an experimental design choice for visual intuition, not a medically or legally certified risk index.
